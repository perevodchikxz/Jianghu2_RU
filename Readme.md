# Следующая остановка — цзянху II · Русский перевод

Неофициальная русская локализация **下一站江湖Ⅱ / Next Stop Jianghu II**: сюжет, диалоги, задания, описания предметов и боевых искусств, а также интерфейс. Русский текст сверен с китайским оригиналом и литературно отредактирован. В оформлении используется кириллический шрифт **Neucha**.

**Установка обычным копированием.** PowerShell, Python, Git, мод-менеджер и установка шрифтов в Windows не нужны.

| Основа | Литературная редактура от 09.10.2026, исправление достижений, оформление Neucha v8 |
| Объём после распаковки | Около **5,34 ГБ**; 19 заменяемых файлов |

Совместимость с другими сборками, платформами и модификациями не проверена. Номер сборки — это не дата обновления. Его можно найти в поле `buildid` файла `steamapps/appmanifest_1606180.acf` своей библиотеки Steam; менять этот файл не нужно.

## Установка за несколько шагов

1. **Закройте игру.** Если уже установлен другой русификатор или мод, заменяющий игровые файлы, сначала восстановите чистые файлы через Steam, как описано ниже.
2. Если скачали архивы, скачайте **оба** файла `Jianghu2-RU-2026.10.11-01-Interface.zip` и `Jianghu2-RU-2026.10.11-02-Text-and-Resources.zip`. Распакуйте оба в **одну общую папку**. Это два самостоятельных ZIP, специальный архиватор или склейка частей не нужны. Если у вас уже есть полная распакованная папка этого выпуска, пропустите этот шаг.
3. Откройте папку игры через Steam: **Библиотека → 下一站江湖Ⅱ → Управление → Просмотреть локальные файлы**. Найдите внутри файл **`下一站江湖Ⅱ.exe`**. Если в открывшейся папке его нет, откройте вложенную папку `下一站江湖Ⅱ`.
4. Из папки **`INSTALL`** этого комплекта скопируйте **`下一站江湖Ⅱ_Data`** в папку, где находится `下一站江湖Ⅱ.exe`. Подтвердите **объединение папок и замену совпадающих файлов**. Не удаляйте существующую папку `_Data`: в комплекте только изменённые файлы, остальные нужны игре.
5. Запустите игру обычным способом через Steam.

Правильное расположение после копирования:

```text
Папка с файлом запуска игры/
├── 下一站江湖Ⅱ.exe
├── UnityPlayer.dll
└── 下一站江湖Ⅱ_Data/
    ├── Managed/
    ├── StreamingAssets/
    └── ...остальные файлы игры...
```

Не помещайте `INSTALL` целиком в игру и не создавайте вторую папку `_Data` внутри существующей. Если Windows не предложила заменить ни одного файла, проверьте выбранную папку.

## Удаление и обновление перевода

Чтобы вернуть оригинальные файлы, закройте игру и откройте в Steam **Свойства игры → Установленные файлы → Проверить целостность файлов игры**. Steam восстановит изменённые файлы. Этот способ также отменяет другие модификации этих же файлов.

Сам комплект не содержит сохранений и не заменяет их. Резервную копию своих сохранений храните отдельно.

После обновления игры сначала проверьте совместимость нового выпуска перевода с новой сборкой. Проверка файлов Steam и обновления могут убрать перевод частично или полностью. Не смешивайте файлы разных выпусков.

## Если что-то не работает

| Симптом | Что проверить |
| --- | --- |
| Игра осталась на китайском | Оба архива распакованы в одну папку; `_Data` скопирована рядом с нужным EXE; замена файлов подтверждена. |
| Часть текста русская, часть нет | Проверьте второй архив и отсутствие файлов другого русификатора. Надписи, нарисованные прямо на изображениях, могут оставаться китайскими. |
| Квадраты вместо букв или старый шрифт | Скопируйте весь комплект заново: GUI и три шрифтовые DLL должны быть из одного выпуска. Отдельно устанавливать Neucha в Windows не требуется. |
| Вылет при открытии меню или при запуске | Восстановите оригинал через Steam, проверьте номер сборки, затем установите весь комплект. Если проблема повторяется, сообщите, какое окно открывали и что делали перед вылетом. |
| Текст не помещается | Укажите разрешение экрана, масштаб интерфейса/текста и приложите снимок проблемного окна. |

Для сообщения об ошибке нужны: версия перевода, сборка игры, название задания или окна, шаги повторения и снимок экрана. Журнал `Player.log`, если он есть, поможет при вылете; перед публикацией проверьте его на личные данные. Место для обратной связи появится после публикации проекта.

## Состав папки

- `INSTALL/` — готовые файлы для копирования в игру.
- `УСТАНОВКА.txt` — короткая инструкция, открывается обычным Блокнотом.
- `VERSION.json` и `SHA256SUMS.txt` — версия, список файлов и контрольные суммы; запускать их не требуется.
- `LICENSES/`, `CREDITS.md` — сведения о шрифте и правах.
- `CHANGELOG.md` — изменения выпуска.
- `FOR_UPLOAD.md` — памятка для будущей публикации.
- `archives/` — два ZIP для раздачи, если вы получили полную папку от автора. Внутри скачанных ZIP вложенных архивов нет.

Если проект размещён на GitHub, русификатор нужно брать из **Releases**. Автоматический архив **Source code (zip)** содержит материалы репозитория и не заменяет игровой комплект.
